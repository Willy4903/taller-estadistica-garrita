¿Qué es un system prompt?

Respuesta en 20 segundos

Un system prompt es el conjunto de reglas que define cómo debe comportarse un asistente de IA antes de que escribas tu primera pregunta: su rol, sus límites, su tono y su formato de respuesta. El prompt del usuario, en cambio, es la tarea de ahora.

Prompt y system prompt: la diferencia

El prompt describe lo que quieres resolver en este momento: 'analiza este archivo y detecta anomalías'. El system prompt describe las reglas permanentes bajo las que quieres que el asistente trabaje: 'eres analista de datos de una institución pública; trabaja solo con los datos proporcionados; no inventes valores; diferencia hechos de inferencias'.

Dicho de forma simple, el system prompt define el comportamiento y el prompt define la tarea. Puedes cambiar la tarea sin tocar las reglas, o cambiar las reglas para que todas las tareas se hagan con otro criterio.

Ejemplo profesional

SYSTEM: Eres analista de datos de una institución pública. Trabaja únicamente con los datos proporcionados. No inventes valores faltantes. Diferencia hechos de inferencias. Comprueba los cálculos antes de concluir. Entrega primero los hallazgos críticos.

USER: Analiza este archivo y detecta anomalías.

Cómo escribir un buen system prompt

Define el rol y el público. Escribe reglas concretas y verificables ('cita siempre el número de página') en lugar de deseos generales ('sé preciso'). Indica qué hacer cuando falte información. Fija el formato de salida. Prueba con casos reales y ajusta.

En productos como Projects, GPTs, Gems o asistentes personalizados, el system prompt suele aparecer como 'instrucciones' del proyecto o del asistente.

Límites

Un system prompt no garantiza obediencia total: el modelo puede equivocarse o ser engañado por contenido externo (prompt injection). Para tareas críticas se combina con verificación humana y permisos acotados.

Preguntas frecuentes

¿El system prompt es lo mismo que las instrucciones personalizadas?

Son conceptos cercanos: ambos fijan reglas persistentes. El nombre y el lugar donde se configuran dependen de cada producto.

¿Puedo ver el system prompt de un servicio?

Normalmente no: lo define el proveedor o el equipo que construyó el asistente. En tus propios proyectos sí puedes escribirlo y editarlo.

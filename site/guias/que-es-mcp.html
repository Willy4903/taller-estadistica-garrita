¿Qué es MCP?

Respuesta en 20 segundos

MCP (Model Context Protocol) es un protocolo abierto, presentado por Anthropic, que define cómo un asistente de IA se conecta con herramientas y fuentes de datos de forma uniforme.

El problema que resuelve

Antes, conectar un asistente con una herramienta exigía una integración a medida para cada combinación. Con MCP, una herramienta expone sus capacidades mediante un servidor y cualquier cliente compatible puede usarlas.

Cómo funciona

Hay un cliente (el asistente o la aplicación) y servidores que exponen herramientas, recursos y plantillas de instrucciones. El modelo decide cuándo usar cada herramienta y el cliente ejecuta la llamada.

Qué cuidar

Cada conexión amplía lo que el asistente puede ver y hacer. Revisa permisos, usa acceso de solo lectura cuando baste, confía solo en servidores de fuentes conocidas y desconfía del contenido externo que pueda traer instrucciones maliciosas.

Preguntas frecuentes

¿MCP es lo mismo que un plugin o un conector?

Son ideas cercanas. MCP es un estándar; los conectores y plugins son la forma en que cada producto lo presenta al usuario.

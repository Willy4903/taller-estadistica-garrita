# taller-estadistica-garrita
Taller de Estadística Aplicada para la Recolección e Interpretación de Datos - INEI

## Catálogo de ecommerce (ropa/calzado)

Aplicación de catálogo dinámico con filtros por género, talla, categoría y color, búsqueda por nombre, carrito con localStorage y ordenamiento. Construida con React + Vite + Tailwind CSS.

### Uso

```bash
npm install
npm run dev
```

Para generar el build de producción:

```bash
npm run build
npm run preview
```
